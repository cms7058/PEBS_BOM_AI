# BOM copilot 内测登录与邀请码验证方案

更新日期：2026-05-10

## 1. 背景

当前项目处于内测阶段，暂时关闭公开订阅、支付和套餐选择流程。用户必须通过邮箱和邀请码验证后，才能进入 BOM 上传与编辑工作台。

内测阶段的目标是：

- 屏蔽个人版、团队版、企业版订阅卡片。
- 通过 PEBS 云函数统一校验内测资格。
- 验证通过后默认进入企业版能力空间。
- 对内测用户设置有效期和使用额度。
- 保留后台管理页面，后续再恢复订阅、支付和套餐管理能力。

## 2. 页面改造

### 2.1 首页 / 访客页

入口：

```text
/guest
```

改造内容：

- 去掉订阅方案卡片。
- 保留现有首页的轻量蓝白视觉风格。
- 将页面文案改为 `BOM copilot 内测版开放`。
- 展示内测准入说明：
  - 邮箱验证
  - 邀请码准入
  - 企业版体验
  - 14 天内测
- 提供 `进入内测登录` 按钮，跳转到 `/login`。

未登录用户访问工作台 `/` 时，前端 `AuthGuard` 会跳转到：

```text
/guest?reason=unauth
```

### 2.2 登录页

入口：

```text
/login
```

登录页输入字段：

- 邮箱
- 邀请码

页面展示权益：

- 默认权限：企业版
- 有效时间：14 天
- BOM 导入/导出：10 / 10

验证通过后：

- 后端创建或更新内测用户。
- 后端创建或更新企业版租户。
- 前端保存登录状态。
- 自动跳转到上传 BOM 页面 `/`。

验证不通过且需要申请邀请码时：

- 不显示红色错误文字。
- 只显示一行：

```text
[申请邀请码]  未注册用户
```

`申请邀请码` 按钮跳转：

```text
https://lingcan.pebs.online/#/pages/copilot/index
```

注意：`申请邀请码` 和 `验证并进入` 两个按钮互斥显示，不能同时出现。

## 3. 云函数调用

前端登录页不会直接请求云函数，而是先请求本项目后端：

```text
POST /admin/internal-login
```

前端传给后端：

```json
{
  "email": "用户邮箱",
  "invite_code": "邀请码"
}
```

后端再调用 PEBS 云函数：

```text
https://fc-mp-ad17509f-ebae-4693-974b-769771dd93c5.next.bspapp.com/pebs-copilot-api
```

后端发送给云函数：

```json
{
  "action": "loginWithInvite",
  "productKey": "bom-copilot",
  "email": "用户邮箱",
  "inviteCode": "邀请码"
}
```

测试成功返回示例：

```json
{
  "code": 0,
  "success": true,
  "valid": true,
  "access": true,
  "status": "active",
  "message": "已授权访问",
  "data": {
    "productKey": "bom-copilot",
    "productName": "Pebs Copilot BOM",
    "userEmail": "cms-74@163.com",
    "inviteCode": "BOM-50O16Z",
    "status": "active",
    "externalUserId": "cms-74@163.com",
    "externalUserName": ""
  }
}
```

当前判断规则：

- `status === "active"`：允许登录。
- `status !== "active"`：提示申请邀请码。
- 云函数返回 `success=false`、`valid=false` 或非成功 `code`：拒绝登录。

后端返回：

```json
{
  "token": "pebs-admin.xxx.xxxxx",
  "user": {
    "id": "...",
    "tenant_id": "beta_xxxxxxxxxxxxxxxx",
    "username": "beta_xxxxxxxxxxxxxxxxxxxx",
    "display_name": "邮箱前缀",
    "role": "owner",
    "email": "用户邮箱",
    "phone": null,
    "status": "active",
    "trial_expires_at": "2026-xx-xxTxx:xx:xx",
    "bom_import_limit": 10,
    "bom_export_limit": 10,
    "bom_import_count": 0,
    "bom_export_count": 0
  }
}
```

前端保存到浏览器：

```text
pebs.admin.token
pebs.current.user
```

## 5. 内测权限规则

内测用户默认配置：

| 项目 | 默认值 |
| --- | --- |
| 租户类型 | enterprise |
| 订阅模式 | 企业版 |
| 有效期 | 14 天 |
| BOM 导入额度 | 10 次 |
| BOM 导出额度 | 10 次 |

上传 BOM：

- 必须携带登录 token。
- 每成功上传一次，导入次数加 1。
- 超过额度后拒绝上传。

导出 xlsx：

- 必须携带登录 token。
- 每成功导出一次，导出次数加 1。
- 超过额度后拒绝导出。

## 6. 自动退出

前端全局监听用户活动：

- 键盘
- 鼠标点击
- 鼠标移动
- 滚动
- 触摸
- 页面可见性变化

如果 5 分钟没有检测到活动，会自动：

- 清除 `pebs.admin.token`
- 清除 `pebs.current.user`
- 跳转到 `/guest?reason=unauth`

## 7. 保留的后台入口

超级管理员后台入口仍然保留：

```text
/bomadmin
```

默认超级管理员：

```text
用户名：admin
密码：admin123456
```

后台页面暂时保留，用于后续恢复订阅、用户、功能开关和内测用户额度管理。
